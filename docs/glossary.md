# Glossary

[Documentation index](README.md)

| Term | Meaning |
| --- | --- |
| Adapter | Framework implementation of one supported app's validation/rendering/lifecycle behavior |
| App instance | A site's named use of a reusable profile, placed on a guest |
| App profile | Reusable requirements/defaults in this library's `apps/` directory |
| Binding | Explicit choice connecting a role/reference to a site-owned fact |
| CD | Protected continuous deployment of reviewed desired source |
| Component | A typed reusable contract owned by the framework |
| Context | Provider, trust, credential-reference and execution environment selected by a guest |
| Custody / ownership receipt | Private evidence identifying an existing owned resource; not an authored acceptance flag |
| Endpoint | A named advertised address/protocol/port or supported internal application endpoint |
| Exposure | Explicit managed DNS publication or HTTP routing selection |
| Fresh | Supported create-only behavior for an absent owned resource; not permission to adopt existing data |
| Guest | The selected Debian LXC target and its infrastructure identity/resources |
| Guest loopback | The guest's `127.0.0.1`, distinct from a container's private namespace |
| HOLD | Unresolved protected attempt/operation marker; ordinary source updates do not clear it |
| Listener | Actual service socket/bind/publication declaration |
| Packet | Private generated JSON/artifacts consumed by the deployment path |
| Readiness | Explicit selected ordering requirement; a value reference alone creates no wait |
| Retained | Update of an existing verified resource, preserving data and identity |
| Runtime profile | Named resource/process/security policy selected by a guest/app |
| Source-only | Reads/validates source; does not contact or mutate a deployment target |
