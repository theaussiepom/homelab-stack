# Public image options

See [Images and updates](guides/images-and-updates.md) for the authoritative image/archive policy and update effects.

- [Home Assistant public](reference/apps/homeassistant-public.md) versus [custom archive](reference/apps/homeassistant.md).
- [Node-RED public](reference/apps/node_red-public.md) versus [custom archive/retained OIDC](reference/apps/node_red.md).
- [Bitwarden](reference/apps/bitwarden.md) selects the literal immutable official image, independently of its private runtime environment.

Public variants never silently replace custom archives, data, palettes or authentication. Profile pages distinguish supported source/controller paths from actual deployed commissioning.
