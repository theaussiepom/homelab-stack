# Update a selected composition

The canonical procedure is [Images and updates](guides/images-and-updates.md). Keep exact published dependencies and regenerate from the consuming site's own source; the public starter is not an installed layout.

Updates to an existing HomeLab-managed installation require current ownership records, a matching backend, unchanged data and credential owners, and preserved protected private inputs. These updates cannot adopt resources that HomeLab does not manage or clear holds left by unresolved operations. [Testing](testing.md) establishes source behavior; actual deployment/service acceptance is separate.
